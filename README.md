## What's inside

| Lab | Topic | Highlights |
|---|---|---|
| [`lab2`](lab2) | HTML structure | Headings, lists, tables, links, images and forms across several practice pages |
| [`lab3`](lab3) | Multi-page sites | Linked "about" pages with shared layout |
| [`lab4`](lab4) | CSS layout | **KSTech** landing page: responsive grid, SVG icons, light/dark grid backgrounds |
| [`lab5`](lab5) | JavaScript fundamentals | Variables and types, arrays and objects, functions and scope, control flow, iteration and array methods, with challenge exercises |
| [`lab6`](lab6) | DOM and events | DOM selection and updates, event handling, 4 challenges, a **to-do list** and a **tic-tac-toe** game |
| [`lab7`](lab7) | DOM exercises | Changing text, styles and classes from code; rendering a user list from data |

## Run it

Everything is static. Open any `index.html` in a browser, or serve the folder:

```bash
git clone https://github.com/tawan230666/engse611_2-67-main-main.git
cd engse611_2-67-main-main
python3 -m http.server 8000   # then open http://localhost:8000/lab6/tic-tac-toe/
```
